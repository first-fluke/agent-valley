# v1.0.0 Release Notes

Agent Valley 1.0.0 is the first stable release of the mission coordinator. It includes durable missions, Chief Director supervision, Technical/Marketing/Design Directors, Actor routing, mission reports, MCP control, and native client integration exports.

Agent-driven installation keeps the initiating agent's vendor and confirmed model as the Chief Director. See [agent setup](../../AGENT_SETUP.md) for installation and readiness checks.

## Runtime and migration

- Use Node.js 26.10.0 or newer and Bun 1.4.2 or newer.
- Rename existing `valley.yaml` project configuration to `av.yaml`.
- Strict OMA completion evidence uses the supported OMA CLI version 15.0.15. See [OMA integration](../guides/oma-integration.md).

## Source installation

```bash
curl -fsSL https://raw.githubusercontent.com/first-fluke/agent-valley/v1.0.0/scripts/install.sh \
  | bash -s -- --ref v1.0.0
```

For unattended installation and client configuration, follow the agent setup document with the same release ref. Existing OMA configuration is preserved.

The release PR runs the full CI suite before automatic merge. The npm publishing workflow builds and verifies the standalone Node distribution from the release tag. See [release checks](release-checks.md) for validation and publication recovery.
