# Agent Valley plugin usage

Agent Valley and its public plugin sources are provided under the repository's [GNU Affero General Public License, version 3](./LICENSE). That license states the permissions, conditions, warranty disclaimer, and liability limitation for this software.

The public plugin supplies instructions for an AV runtime you configure. It does not include a hosted execution service or a connected model account. Install and configure AV in the intended project before delegating work. Plugin installation does not grant permissions to a repository, enable client trust, or approve an action on your behalf.

Your agent client, model provider, identity provider, hosting service, and configured integrations have their own terms and charges. Configure the accounts, budgets, permissions, verification criteria, and reporting recipients appropriate to your use. Estimated costs and accepted orders do not guarantee a completed or verified result.

The Chief Director and Actors operate within the authorization and constraints supplied for a mission. Review the saved result and verification evidence before relying on it. Publishing, deployment, purchases, changes to budgets, and contact with others require the authorization applicable to that action.

See [data handling](./PRIVACY.md) for the plugin's documented data flows, [installation](./README.md) for setup, and [GitHub issues](https://github.com/first-fluke/agent-valley/issues) for project support. These files describe the open-source package; an operator offering a hosted AV service must provide the terms and data disclosures for that deployment.
